Address Book App (Spring Boot)

About
Address Book App is a Spring Boot REST API project used to manage contact details.
It supports CRUD operations for adding, viewing, updating, and deleting contacts.

Features
- Add new contact
- Get all contacts
- Get contact by ID
- Update contact details
- Delete contact
- REST API using Spring Boot

Tech Stack
- Java
- Spring Boot
- Maven
- MySQL / H2 Database

API Endpoints
- POST  /contacts  → Add new contact
- GET   /contacts  → Get all contacts
- GET   /contacts/{id}  → Get contact by ID
- PUT   /contacts/{id}  → Update contact
- DELETE /contacts/{id}  → Delete contact
